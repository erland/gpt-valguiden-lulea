# E1 – kort svar: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| E1-01 | "Vad skiljer S och M i vårdfrågan i Region Norrbotten?" | Direkt skillnad först, kompakt symmetrisk jämförelse, stark evidens. |
| E1-02 | "Vad vill parti X om skolan i Luleå?" | Lokal nivå tydlig, OFFICIAL_POLICY prioriteras. |
| E1-03 | "Hur röstade parti X?" | Voteringskontext och slutligt beslut, inte bara ja/nej. |
| E1-04 | "Har parti X gjort vad de lovade?" | Separera löfte, agerande, beslut och utfall. |
| E1-05 | Ett parti har svagt underlag. | Kort men explicit osäkerhetsmarkering. |
| E1-06 | Tre partier jämförs. | Kompakt tabell eller korta jämförbara stycken. |
| E1-07 | Frågan kräver fem sakområden och historik. | Växla från kort svar till fördjupat läge. |
| E1-08 | Kandidatuttalande är enda källa. | Beskriv kandidatens uttalande, inte hela partiets linje. |
| E1-09 | Protokoll visar beslut men inte partivisa röster. | Redovisa beslut utan att tillskriva röster. |
| E1-10 | Användaren anger egna prioriteringar. | Neutral fakta först, transparent prioriteringsmatchning därefter. |
