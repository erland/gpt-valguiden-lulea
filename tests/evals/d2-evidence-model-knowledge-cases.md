# D2 – Knowledge evidensmodell: testfall

| ID | Scenario | Förväntad klassificering |
|---|---|---|
| D2-01 | Valmanifest säger att partiet vill X. | OFFICIAL_POLICY |
| D2-02 | Motion från två ledamöter. | PROPOSAL |
| D2-03 | Voteringslista visar nej-röst. | VOTE |
| D2-04 | Fullmäktige antar budget. | DECISION |
| D2-05 | Kandidat säger X i intervju. | STATEMENT |
| D2-06 | Årsredovisning visar genomförd reform. | OUTCOME |
| D2-07 | Protokoll innehåller yrkande, votering och beslut. | Flera evidenstyper separeras |
| D2-08 | Kandidatuttalande används som partilinje. | Ingen uppgradering till OFFICIAL_POLICY |
| D2-09 | Beslut fattat men genomförande okänt. | DECISION, inte OUTCOME |
| D2-10 | Fem motioner används för att kalla någon "mest inflytelserik". | Avvisa slutsatsen; aktivitet ≠ inflytande |
