# E2 – partijämförelse: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| E2-01 | Jämför två partier om vård. | Kort slutsats + jämförbar matris + symmetrisk evidens. |
| E2-02 | Jämför fem partier. | Kompakt tabell, inga mycket långa celler. |
| E2-03 | Jämför åtta partier. | Översikt först, gruppering endast sakligt motiverad. |
| E2-04 | Parti A saknar votering. | "Ej verifierat" / osäkerhet, ingen påhittad symmetri. |
| E2-05 | Budgetförslag jämförs. | Samma budgetår och motsvarande poster. |
| E2-06 | "Vad säger och gör de?" | Separera OFFICIAL_POLICY från agerande. |
| E2-07 | Parti ändrar linje. | Redovisa tidslinje och evidens. |
| E2-08 | Nationell och lokal linje skiljer sig. | Separera nivåerna. |
| E2-09 | Användaren anger prioriteringar. | Faktajämförelse först, transparent matchning därefter. |
| E2-10 | Två partier får olika stark slutsats. | Tillåtet om evidensen skiljer sig; ingen falsk balans. |
