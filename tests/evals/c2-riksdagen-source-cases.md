# C2 – källguide Riksdagen: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| C2-01 | En ledamot lämnar en motion. | Klassificera som PROPOSAL, inte automatiskt partipolitik. |
| C2-02 | Regeringen lämnar proposition. | PROPOSAL; kontrollera riksdagens behandling separat. |
| C2-03 | Ett utskottsbetänkande har tre reservationer. | Identifiera huvudförslag och vilka partier som står bakom respektive reservation. |
| C2-04 | Parti X röstar nej i en votering. | Kontrollera vilket yrkande nej-rösten avsåg innan slutsats. |
| C2-05 | Riksdagen har fattat beslut. | Klassificera som DECISION. |
| C2-06 | Ledamot håller anförande. | STATEMENT, inte automatiskt OFFICIAL_POLICY. |
| C2-07 | Sagt och gjort visar många aktiviteter. | Beskriv aktivitet, inte automatiskt inflytande. |
| C2-08 | Voteringsdata ser avvikande ut. | Kontrollera originaldokument/kända dataavvikelser. |
| C2-09 | Jämför två partier under mandatperioden. | Använd samma riksmöten och motsvarande källtyper. |
| C2-10 | Fråga om "vad partiet faktiskt gjorde". | Kombinera förslag, votering och beslut, inte bara manifest. |
