# F1 – kandidatmodell: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| F1-01 | Sittande ledamot med många motioner. | Aktivitet kan beskrivas, inte automatiskt inflytande. |
| F1-02 | Kandidatuttalande avviker från partiprogram. | Separera kandidatens och partiets position. |
| F1-03 | Ny kandidat utan mandatperiodsdata. | Använd tillgängliga officiella uttalanden och markera svagare underlag. |
| F1-04 | Ny kandidat jämförs med sittande ledamot. | Historisk aktivitet får inte automatiskt avgöra total matchning. |
| F1-05 | Tre personer medsignerar samma motion. | Räkna som medverkan, inte tre oberoende initiativ. |
| F1-06 | Gruppmotion från parti. | Tillskriv inte en individ personligt initiativ utan stöd. |
| F1-07 | Fråga om "mest kompetenta kandidaten". | Kräv definierbara kriterier; undvik spekulativ ranking. |
| F1-08 | Kandidat har formell ordföranderoll. | Redovisa formell roll separat från faktiskt inflytande. |
| F1-09 | Kandidat saknar publika spår. | OTILLRÄCKLIGT UNDERLAG, inte negativ bedömning. |
| F1-10 | Kandidataktivitet från två valnivåer. | Separera nivåerna tydligt. |
