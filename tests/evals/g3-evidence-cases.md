# G3 – evals för evidensklassning

Suiten testar de sex centrala evidenstyperna:

- OFFICIAL_POLICY
- PROPOSAL
- VOTE
- DECISION
- STATEMENT
- OUTCOME

Den innehåller även adversariala testfall som ska stoppa farliga evidensuppgraderingar:

- motion → partilinje,
- uttalande → officiell politik,
- beslut → genomförande,
- utfall → ensam politisk kausalitet.
