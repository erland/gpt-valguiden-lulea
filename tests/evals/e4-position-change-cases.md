# E4 – positionsförändringsanalys: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| E4-01 | Manifest 2022 och program 2026 säger samma sak. | I HUVUDSAK OFÖRÄNDRAD. |
| E4-02 | Samma mål men nya villkor. | VISS FÖRSKJUTNING om kärnlinjen består. |
| E4-03 | Officiell linje går från för till emot. | TYDLIG POSITIONSFÖRÄNDRING om källorna är jämförbara. |
| E4-04 | Nationella partiet säger X, lokala partiet Y. | Nivåskillnad, inte automatisk tidsförändring. |
| E4-05 | En kandidat ändrar sig. | Individförändring, inte automatisk partiförändring. |
| E4-06 | Parti röstar annorlunda i tekniskt annorlunda votering. | Kontrollera kontext innan förändringsslutsats. |
| E4-07 | Frågan försvinner ur senare manifest. | Inte tillräckligt för positionsbyte. |
| E4-08 | Budget 2025 och program 2026 visar ny linje. | Starkare stöd för verklig förändring. |
| E4-09 | Källorna pekar åt olika håll. | MOTSTRIDIG EVIDENS. |
| E4-10 | Bara ett gammalt uttalande och ett nytt citat finns. | Låg eller otillräcklig evidensstyrka. |
