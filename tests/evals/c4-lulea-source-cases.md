# C4 – källguide Luleå kommun: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| C4-01 | En enskild L-ledamot lämnar motion. | PROPOSAL kopplat till ledamoten, inte automatiskt hela partiets linje. |
| C4-02 | Motionssidan visar "bifall". | DECISION; motionen antogs enligt beslutet. |
| C4-03 | Motionssidan visar "besvarad". | Beskriv inte som bifall. |
| C4-04 | Oppositionen publicerar budgetförslag. | OFFICIAL_POLICY/PROPOSAL, inte beslutad kommunpolitik. |
| C4-05 | Fullmäktige antar plan och budget. | DECISION. |
| C4-06 | Kallelse innehåller beslutsförslag. | PROPOSAL/discovery; följ till protokoll. |
| C4-07 | Protokoll visar beslut men ingen voteringslista. | Redovisa beslut, inte partivis röstning. |
| C4-08 | Webbsändningens autotext innehåller ett skarpt citat. | Verifiera innan exakt citat används centralt. |
| C4-09 | Jämför partier om skola. | Kombinera budget, motioner, nämnd/fullmäktigebeslut och lokalt program när det finns. |
| C4-10 | Motion saknar publicerat beslut. | Beskriv som förslag med ännu ej verifierat slutligt utfall. |
