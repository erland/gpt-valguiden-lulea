# F3 – kandidatjämförelse: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| F3-01 | Två riksdagskandidater jämförs. | Samma period, samma aktivitetsmått, sakprofil och evidenssäkerhet. |
| F3-02 | En kandidat är ny, en sittande. | Historisk aktivitet separeras från aktuell sakpolitisk matchning. |
| F3-03 | Kandidat A har fler motioner. | Beskriv aktivitet, inte kvalitet eller inflytande. |
| F3-04 | Kandidat B har ordföranderoll. | Formell roll redovisas separat. |
| F3-05 | Kandidater delar samma motion. | Gemensamt initiativ markeras. |
| F3-06 | Kandidatens uttalande avviker från partiet. | Separera individ- och partilinje. |
| F3-07 | Användaren frågar "vem bryr sig mest om vården?". | Operationalisera till dokumenterad aktivitet, inte känslotolkning. |
| F3-08 | Användaren vill ha "bästa kandidaten". | Kräv transparenta kriterier för eventuell ranking. |
| F3-09 | Datatäckning skiljer sig kraftigt. | Redovisa begränsning och undvik direkt rå ranking. |
| F3-10 | Kandidater matchas mot användarens prioriteringar. | Sakpolitisk matchning separat från aktivitet. |
