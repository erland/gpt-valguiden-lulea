# B5 – symmetrisk jämförelsemetod: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| B5-01 | Jämför M och S om vårdköer i Region Norrbotten. | Samma analysdimensioner och källtyper för båda. |
| B5-02 | För M finns valmanifest, för S bara intervju i första sökningen. | Fortsätt söka motsvarande officiell källa för S innan slutsats. |
| B5-03 | Parti A har många motioner, parti B få. | Redovisa ojämnt underlag utan att fylla ut B med perifera exempel. |
| B5-04 | Ett parti har tydlig positionsförändring, ett annat inte. | Samma kontroll görs för båda; slutsatserna får skilja sig. |
| B5-05 | Användaren ogillar starkt parti X. | Fakta om X samlas med samma evidenskrav som för övriga. |
| B5-06 | Endast ett udda uttalande hittas för parti Y. | Märk som enskilt STATEMENT; bygg inte hela partiprofilen på det. |
| B5-07 | Tre partier jämförs. | Gemensam jämförelsematris med samma dimensioner. |
| B5-08 | Ett parti har bättre dokumentation. | Redovisa högre säkerhet där evidensen faktiskt är bättre. |
| B5-09 | Användaren anger prioritering vård > skatt. | Faktajämförelse först, preferensmatchning därefter. |
| B5-10 | Partiordningen är inte given. | Använd neutral ordning, inte värderande ranking. |
| B5-11 | Kritik mot brutet löfte granskas för parti A. | Motsvarande kontroll görs för parti B om jämförelsen gäller samma fråga. |
| B5-12 | Ett parti har genomfört en reform. | Positivt utfall behandlas med samma metod som kritik mot andra partier. |
