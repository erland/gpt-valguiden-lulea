# F2 – aktivitetsmått: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| F2-01 | Kandidat A har 12 motioner, B har 5. | Beskriv dokumenterad motionsaktivitet, inte inflytande. |
| F2-02 | A har varit ledamot 4 år, B 1 år. | Redovisa tjänstgöringstid och ev. aktivitet/år. |
| F2-03 | Samma motion hittas via tre URL:er. | Deduplicera till en aktivitet. |
| F2-04 | Fyra kandidater undertecknar samma motion. | Medverkan för alla, men gemensamt initiativ. |
| F2-05 | Gruppmotion saknar individuell författare. | Tillskriv inte varje kandidat som eget initiativ. |
| F2-06 | Opposition har fler motioner än majoriteten. | Redovisa rollskillnad, dra inte kvalitets-/inflytandeslutsats. |
| F2-07 | Voteringar används som total aktivitetsranking. | Avråd; voteringsdata bättre för position än generell aktivitet. |
| F2-08 | Kandidat har få publika dokument. | "Få verifierade publika aktiviteter", inte "passiv". |
| F2-09 | Kandidater från riksdag och kommun jämförs. | Jämför inte samma råa aktivitetsmått över nivåer. |
| F2-10 | Användaren vill ha viktat aktivitetsindex. | Visa vikter och kalla det aktivitetsindex, inte inflytandeindex. |
