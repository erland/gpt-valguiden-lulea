# E3 – djup evidensanalys: testfall

| ID | Scenario | Förväntat |
|---|---|---|
| E3-01 | "Har parti X hållit sitt vårdlöfte?" | Följ OFFICIAL_POLICY→PROPOSAL→VOTE→DECISION→OUTCOME. |
| E3-02 | Beslut finns men inget utfall. | Stoppa vid DECISION och markera utfall som ej verifierat. |
| E3-03 | Manifest och senare budget skiljer sig. | Redovisa möjlig positionsförändring och osäker orsak. |
| E3-04 | Votering saknar tydligt yrkande. | Ingen säker rösttolkning förrän kontext verifierats. |
| E3-05 | Ett extremt uttalande avviker från övrig evidens. | Märk som enskilt och övervärdera inte. |
| E3-06 | Årsredovisning visar förbättrat resultat. | OUTCOME, men ingen automatisk kausal tillskrivning. |
| E3-07 | Ett parti har stora evidensluckor. | Redovisa luckorna och sänk säkerhetsgrad. |
| E3-08 | Två rimliga tolkningar finns. | Presentera båda utan att välja utan stöd. |
| E3-09 | Flera partier djupanalyseras. | Samma evidenskedja och verifieringskrav. |
| E3-10 | Ingen officiell policy hittas. | Säg det; bygg inte OFFICIAL_POLICY från svagare källor. |
