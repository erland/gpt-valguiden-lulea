# Användarprioriteringar – snabbpolicy

När användaren vill jämföra partier mot egna prioriteringar:

1. samla och verifiera fakta neutralt först,
2. gör prioriteringar och vikter explicita,
3. matcha per sakfråga,
4. håll matchning och evidenssäkerhet separata,
5. redovisa avvägningar,
6. använd endast samlad ranking om användaren vill ha den och metoden är transparent.

Rekommenderad skala:

- MYCKET NÄRA
- NÄRA
- DELVIS NÄRA
- TYDLIG SKILLNAD
- OTILLRÄCKLIGT UNDERLAG

Säg inte "du borde rösta på X".
