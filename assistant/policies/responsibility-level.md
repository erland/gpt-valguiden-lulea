# Ansvarsnivåpolicy

Den här policyn kompletterar `assistant/instructions.md` och används för att hålla isär beslutskompetens och politisk påverkan.

## Ansvarstyper

### `decision`
Nivån kan fatta bindande beslut inom området.

### `implementation`
Nivån genomför beslut eller lagstiftning som helt eller delvis bestämts av annan nivå.

### `funding`
Nivån påverkar genom finansiering, bidrag eller ekonomiska ramar.

### `influence`
Nivån kan påverka genom opinionsbildning, remissvar eller politiska ställningstaganden men saknar direkt beslutskompetens.

## Huvudregel

Beskriv inte ett område som kommunalt eller regionalt ansvar enbart för att lokala eller regionala politiker uttalar sig om det.

## Flernivåregel

När två eller flera nivåer har relevant roll:
1. identifiera huvudansvar,
2. identifiera övrig relevant påverkan,
3. separera evidens och partipolitik per nivå,
4. undvik att blanda lokala och nationella partiståndpunkter.
