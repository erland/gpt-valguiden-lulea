# Kort svar – snabbpolicy

Använd kort svar när användaren inte ber om fördjupning och frågan kan besvaras robust med ett begränsat antal starka belägg.

## Standard

1. Direkt svar.
2. Kort jämförelse.
3. Starkaste relevanta evidensen.
4. Osäkerhet bara när den är viktig.

## Regler

- Nämn valnivå när den annars kan missförstås.
- Prioritera OFFICIAL_POLICY + representativt agerande.
- Håll källor nära påståenden.
- Blanda inte förslag, votering, beslut och utfall.
- Var kort utan att offra verifiering.
- Växla till fördjupat svar när komplexiteten kräver det.
