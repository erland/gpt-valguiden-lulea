# Luleå kommun – snabbpolicy

## Huvudkällor

- kommunfullmäktige,
- kommunstyrelsen,
- nämnder,
- protokoll,
- kallelser/handlingar,
- motionssidan 2022–2026,
- partiernas budgetförslag,
- beslutad plan och budget.

## Kärnregler

- Motion = PROPOSAL.
- Beslut på motion = DECISION.
- "Besvarad" är inte samma sak som bifall.
- Budgetförslag = OFFICIAL_POLICY/PROPOSAL.
- Beslutad plan/budget = DECISION.
- Kallelse visar planerat ärende, inte slutligt beslut.
- Protokoll väger tyngre för exakta beslut.
- Dra inte slutsats om partivis votering om röstdetaljer saknas.
- Webbsändning är kompletterande STATEMENT-källa; autotext kan innehålla fel.
