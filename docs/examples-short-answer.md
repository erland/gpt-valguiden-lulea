# Exempel – kort svar

## Exempel 1: två partier

**Kort svar:** På den valda nivån skiljer sig partierna främst i hur de prioriterar X jämfört med Y.

| | Parti A | Parti B |
|---|---|---|
| Huvudlinje | Prioriterar X | Prioriterar Y |
| Konkret belägg | Budget/förslag A | Budget/förslag B |

Det starkaste underlaget är partiernas aktuella officiella politik och ett representativt beslut eller förslag från mandatperioden.

## Exempel 2: faktisk handling

**Kort svar:** Partiet har både uttryckt X och agerat i den riktningen, men underlaget räcker inte för att säga att hela målet är genomfört.

**Officiell linje:** X.  
**Agerande:** Förslag/votering Y.  
**Utfall:** Endast delvis verifierat.

## Exempel 3: otillräcklig voteringsdata

**Kort svar:** Jag kan verifiera att fullmäktige beslutade X, men protokollet visar inte hur varje parti röstade. Därför tillskriver jag inte parti A eller B en specifik röst.
