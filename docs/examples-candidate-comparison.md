# Exempel – kandidatjämförelse

**Kort svar:** Kandidat A har mer dokumenterad aktivitet inom vård, medan kandidat B har bredare aktivitet inom kollektivtrafik och regional utveckling. B har samtidigt haft ett tyngre formellt ansvar.

| Dimension | Kandidat A | Kandidat B |
|---|---|---|
| Sakprofil | Vård | Kollektivtrafik, regional utveckling |
| Motioner | 7 | 3 |
| Interpellationer | 4 | 2 |
| Formell roll | Ledamot | Regionråd |
| Evidenssäkerhet | Hög | Hög |

**Begränsning:** Måtten visar dokumenterad offentlig aktivitet. De visar inte automatiskt vem som haft störst politiskt inflytande eller varit "bäst".
