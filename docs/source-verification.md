# Källverifiering

## 1. Syfte

Det här dokumentet definierar hur Valguiden ska verifiera en källa innan den används som stöd för ett centralt politiskt sakpåstående.

Målet är att minska risken för:

- felaktiga källor,
- feltolkade dokument,
- fel valnivå,
- fel aktör,
- gammal information som presenteras som aktuell,
- felaktiga direktlänkar,
- slutsatser som går längre än källan stödjer.

## 2. Grundregel

> En källa ska inte bara vara relevant. Den ska också vara verifierad för det konkreta påstående den används till.

## 3. VERIFY-1 – Avsändare

Kontrollera vem som faktiskt publicerat materialet.

Exempel:

- Sveriges riksdag,
- Valmyndigheten,
- Region Norrbotten,
- Luleå kommun,
- officiell partiorganisation,
- enskild kandidat,
- etablerat nyhetsmedium.

Viktigt:
- en partidomän är inte samma sak som myndighetskälla,
- en kandidats personliga sida är inte automatiskt partiets officiella linje,
- en återpublicerad artikel är inte originalkällan.

## 4. VERIFY-2 – Dokumenttyp

Identifiera vilken typ av källa det är.

Exempel:

- valmanifest,
- motion,
- proposition,
- betänkande,
- protokoll,
- votering,
- budget,
- pressmeddelande,
- intervju,
- årsredovisning.

Dokumenttypen styr evidensklassningen.

## 5. VERIFY-3 – Datum

Kontrollera:
- publiceringsdatum,
- beslutsdatum,
- vilken mandatperiod materialet gäller.

Vid aktuell politik:
- nyare officiell källa väger normalt tyngre än äldre.

Vid historisk analys:
- äldre källor ska bevaras för att visa förändring över tid.

## 6. VERIFY-4 – Valnivå

Kontrollera att källan gäller rätt nivå:

- Riksdagen,
- Region Norrbotten,
- Luleå kommun.

Exempel på fel:
- nationell partisida används som bevis för lokal partipolitik,
- regionalt uttalande används som om kommunen beslutat,
- kommunal motion används som bevis för riksdagspartiets nationella linje.

## 7. VERIFY-5 – Aktör

Kontrollera vem uppgiften gäller:

- hela partiet,
- partigruppen,
- flera ledamöter,
- enskild ledamot,
- kandidat,
- regeringen,
- regionstyrelsen,
- kommunstyrelsen,
- fullmäktige.

Språket i svaret ska matcha aktören.

## 8. VERIFY-6 – Påståendestöd

Ställ frågan:

> Stödjer källan faktiskt just det påstående jag vill göra?

Exempel:

Källa:
> Ledamot X motionerar om Y.

Tillåten slutsats:
> Ledamot X har föreslagit Y.

Inte automatiskt tillåten:
> Parti X vill införa Y.

## 9. VERIFY-7 – Direktlänk

Kontrollera att länken leder till:

- rätt dokument,
- rätt protokoll,
- rätt beslut,
- rätt manifest,
- rätt partisida.

Undvik om möjligt:
- startsidor,
- generella söksidor,
- arkivöversikter,
- sökresultat.

Om bara en översiktssida finns:
- använd den,
- men säg inte att den är originaldokument om den bara sammanfattar.

## 10. VERIFY-8 – Originalkälla

Kontrollera om en bättre originalkälla finns.

Exempel:

Medieartikel:
> Parti X föreslår Y.

Sök då efter:
- manifest,
- motion,
- pressmeddelande,
- officiell intervju,
- budgetförslag.

## 11. VERIFY-9 – Beslutskontext

För beslut och voteringar kontrollera:

- vilket ärende,
- vilket yrkande,
- vilket organ,
- vilket steg i processen,
- om beslutet är slutligt,
- om det gick vidare till annan instans.

## 12. VERIFY-10 – Voteringskontext

För en votering kontrollera:

- vad ja betydde,
- vad nej betydde,
- vilket förslag som stod mot vilket,
- om det var en reservation,
- hur slutbeslutet blev.

Ett isolerat "ja" eller "nej" får inte användas utan denna kontext.

## 13. VERIFY-11 – Aktualitet

För källor som beskriver aktuell politik kontrollera:

- om sidan fortfarande är aktuell,
- om nyare program/budget/manifest finns,
- om partiet ändrat linje,
- om kandidaten fortfarande är aktuell.

Gamla sidor ska dateras tydligt.

## 14. VERIFY-12 – Geografisk träffsäkerhet

För lokal/regional analys kontrollera att materialet verkligen gäller:

- Luleå kommun,
- Region Norrbotten,
- rätt valkrets när relevant.

Särskilt viktigt för partier som har separata lokalorganisationer.

## 15. VERIFY-13 – Intern konsistens

Kontrollera om källan motsäger:

- annan officiell källa,
- senare dokument,
- beslut,
- votering,
- utfall.

Om konflikt finns:
- redovisa den,
- välj inte tyst en sida.

## 16. VERIFY-14 – Källans fullständighet

Sökresultat, snippets eller korta sammanfattningar kan vara ofullständiga.

Om slutsatsen är viktig:
- öppna hela dokumentet,
- läs relevant kontext,
- undvik att dra slutsats från en lösryckt mening.

## 17. VERIFY-15 – Citat

För exakta citat:

- kontrollera ordalydelsen,
- kontrollera vem som sagt det,
- kontrollera datum och sammanhang.

Om källan är automattextad video:
- markera osäkerhet,
- undvik centrala exakta citat utan ytterligare kontroll.

## 18. VERIFY-16 – Sekundärkälla

När sekundärkälla används:

- kontrollera vilken originalkälla artikeln bygger på,
- skilj journalistens analys från citerade fakta,
- attribuera värderande formuleringar,
- använd inte rubrik ensam som evidens.

## 19. VERIFY-17 – Osäker länk eller källa

Om länken verkar trasig, omdirigerad eller oklar:
- försök hitta motsvarande officiell källa,
- använd inte en osäker URL som om den vore verifierad.

## 20. VERIFY-18 – Dubbletter

Flera webbträffar kan i själva verket bygga på samma källa.

Räkna inte:
- fem artiklar om samma pressmeddelande

som fem oberoende belägg.

## 21. VERIFY-19 – Evidensstyrka

Bedöm gärna evidensen i termer av:

- starkt direkt stöd,
- tydligt stöd,
- indirekt stöd,
- begränsat stöd,
- otillräckligt stöd.

Styrkan ska spegla källans faktiska förmåga att bära slutsatsen.

## 22. VERIFY-20 – Slutlig verifieringschecklista

Före centralt påstående:

- [ ] rätt avsändare
- [ ] rätt dokumenttyp
- [ ] rätt datum
- [ ] rätt valnivå
- [ ] rätt aktör
- [ ] källan stödjer påståendet
- [ ] direktlänk kontrollerad
- [ ] originalkälla prioriterad
- [ ] beslutskontext förstådd
- [ ] voteringskontext förstådd när relevant
- [ ] aktualitet kontrollerad
- [ ] geografisk träffsäkerhet kontrollerad
- [ ] källkonflikter kontrollerade
- [ ] fullständig kontext läst vid viktiga slutsatser
- [ ] citat verifierat om exakt citat används
- [ ] dubbletter inte felaktigt räknade som oberoende evidens

## 23. Verifieringsresultat

En källa kan efter kontroll få någon av följande statusar:

### VERIFIED
Källan kan bära det avsedda påståendet.

### VERIFIED_WITH_LIMITATIONS
Källan är användbar men kräver tydlig begränsning.

### DISCOVERY_ONLY
Källan är användbar för att hitta bättre källa men bör inte bära slutsatsen.

### REJECTED
Källan ska inte användas för det avsedda påståendet.

## 24. Rekommenderad intern struktur

Vid komplex research kan GPT:n mentalt hålla:

| Fält | Exempel |

| Source | Riksdagens betänkande |
| Status | VERIFIED |
| Evidence type | DECISION |
| Date | 2026-02-15 |
| Level | Riksdagen |
| Actor | Riksdagen |
| Claim supported | Riksdagen beslutade X |
| Limitations | Ingen |
| URL checked | Ja |

## 25. Källverifiering före syntes

Innan flera källor vägs ihop:

1. verifiera källorna var för sig,
2. klassificera evidensen,
3. kontrollera konflikter,
4. först därefter gör syntesen.

Undvik att syntetisera först och leta stöd i efterhand.
