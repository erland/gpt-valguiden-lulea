# Dokumentationsöversikt

Det här dokumentet beskriver de styrande projektunderlagen för Valguiden.

## 1. Behovs- och målbild

Se [`needs-and-target-state.md`](needs-and-target-state.md).

Dokumentet definierar:
- syfte,
- stödda valnivåer,
- huvudsakliga användarbehov,
- källprincip,
- evidensmodell,
- neutralitetsprinciper,
- risker,
- ambitionsnivå för version 1.0.

## 2. Målarkitektur och projektprofil

Se [`target-architecture.md`](target-architecture.md).

Dokumentet definierar:
- projektprofil,
- capabilities,
- källarkitektur,
- webbresearchflöde,
- statisk Knowledge,
- svarsarkitektur,
- teststrategi,
- distributions- och releaseprofil.

## 3. Utvecklingsplan

Se [`development-plan.md`](development-plan.md).

Dokumentet bryter ned projektet i steg från projektgrund till release candidate och version 1.0.0.

## Styrande princip

Vid konflikt mellan dokument ska den mest specifika och senast fastställda projektregeln gälla, men centralt GPT-beteende ska i slutänden uttryckas i den canonical instruktionen.
