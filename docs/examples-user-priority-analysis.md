# Exempel – analys utifrån användarprioriteringar

## Dina prioriteringar

| Fråga | Vikt |
|---|---:|
| Vård | 50 % |
| Kollektivtrafik | 30 % |
| Skatt | 20 % |

## Matchning

| Parti | Vård | Kollektivtrafik | Skatt | Evidenssäkerhet |
|---|---|---|---|---|
| Parti A | Mycket nära | Nära | Tydlig skillnad | Hög |
| Parti B | Nära | Delvis nära | Mycket nära | Medelhög |

## Samlad syntes

Med den här viktningen ligger Parti A närmare i dina två högst prioriterade frågor. Parti B ligger däremot tydligare närmare i skatt.

Det här är en jämförelse mot de prioriteringar och vikter du angett, inte en generell bedömning av vilket parti som är "bäst".
