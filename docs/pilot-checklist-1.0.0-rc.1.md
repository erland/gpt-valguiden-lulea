# Pilotchecklista – Valguiden v1.0.0-rc.1

Använd RC:n i realistiska frågor och registrera avvikelser.

Kontrollera särskilt:
- rätt valnivå väljs,
- ansvarsfördelning förklaras korrekt,
- originalkällor prioriteras,
- varje viktigt sakpåstående kan spåras,
- voteringskontext är korrekt,
- motion/förslag inte blandas ihop med beslut,
- beslut inte blandas ihop med utfall,
- partier behandlas med samma metod,
- användarprioriteringar påverkar matchning men inte faktainsamling,
- individ och parti hålls isär,
- svaren är begripliga och proportionerliga i längd.

För varje pilotbugg:
1. dokumentera reproduktionsprompt,
2. klassificera severity,
3. ange förväntat beteende,
4. skapa permanent regressionstest,
5. fixa i canonical/policy/Knowledge där det hör hemma.
